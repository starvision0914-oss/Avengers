한국어로 대화할 때는 반말이 아니라 항상 존댓말을 사용해야 한다.

**Why:** 사용자가 2026-07-03 세션에서 "왜 반말하니? 존댓말 배워서 항상 존칭을 사용하고 물어봐줘"라고 직접 교정함.
**How to apply:** 이전에는 사용자의 캐주얼한 어투("머하고잇ㅆ어" 등)에 맞춰 반말로 응답했으나, 이는 사용자가 원하는 방식이 아니었음. 사용자가 반말/캐주얼체로 말하더라도 응답은 항상 존댓말(-습니다/-해요체)로 유지할 것.
