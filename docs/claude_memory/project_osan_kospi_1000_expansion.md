[[project_osan_kospi_news_series]] 600개 완성 이후, 사용자가 2026-07-13 목표를 1000개(+400)로 상향. **여러 세션에서 동시 병행 진행 중** — 한 세션이 계속 신규 종목을 추가하면, 이 세션은 지금까지 작성된 글을 다듬고 마무리하는 역할로 전환(2026-07-13 사용자 지시). 신규 종목 추가 재개 전 반드시 사용자에게 "다른 세션도 동시 진행 중인지" 확인할 것 — 동시 진행 시 중복 회사 리스크 있음(실제로 확인 도중 다른 세션이 6개+3개를 실시간 추가하는 걸 목격, 다행히 회사명 중복 0건이었음).

**이번 세션에서 추가한 20개(2026-07-13)**: 삼천리, 삼일제약, 대봉엘에스, 티움바이오, 사조대림, RBW, 명문제약, 에이블씨엔씨, 동운아나텍, 인터로조, 삼양라운드스퀘어, 엔젠바이오, 덕산하이메탈, 삼영전자공업, 우진플라임, 이지바이오, 서진시스템, 한국석유공업, 유니드, 삼진엘앤디. 전부 1500자+/키워드3회+/대표이미지/FAQ/표 정상 확인.

**새로 발견한 함정 — 회사명 검색 오염(기존 기록에 없던 신규 패턴)**:
- "삼천리" 검색 → 전혀 다른 회사 "삼천리자전거" 데이터가 섞여 나옴
- "삼일제약" 검색 → 이름 비슷한 "삼진제약" 데이터가 섞여 나옴
- "삼영전자" 검색 → "삼성전자" 데이터가 섞여 나옴
- "현대에버다임" 검색 → "현대오토에버"/"현대차" 데이터만 나오고 정작 원하는 회사 데이터 없음
- **대응**: 회사명이 다른 유명 회사와 비슷하면 종목코드(예: "삼천리 004690")를 함께 검색어에 넣어 재검색. Threads.com 같은 SNS 출처 수치는 [[project_osan_kospi_news_series]]에 이미 명시된 대로 신뢰 금지(재확인).

**중복 체크 방법 개선**: 기존에는 `sed`로 제목 첫 단어만 잘라 회사 리스트를 만들었는데, "CJ ENM"처럼 여러 단어 회사명이 "CJ"로 잘려 실제 발행된 글(ID 982, CJ ENM)을 못 찾고 중복 작성할 뻔함. **이후로는 전체 제목 substring grep + `wp post list --s="회사명"` 워드프레스 직접 검색 이중 확인으로 전환**. 향후 재개 시에도 이 방식 유지할 것.

**상장폐지/부실 위험 스킵 사례**: 코스나인(감사의견 거절, 상장폐지 결정 후 이의신청 개선기간), 쌍용C&E(상장폐지 진행) — 위험 신호 있으면 후보에서 제외.

**추가 20개(2026-07-13, 같은 세션 이어서)**: 고려아연, 영풍, 미래산업, 삼아알미늄, 차백신연구소, 메드팩토, 케이피에프, S&T모티브, 부국철강, 현대힘스, 한국투자금융지주, 종근당홀딩스, JW중외제약, 휴온스글로벌, OK금융그룹, iM증권, KG케미칼, 코오롱플라스틱, AK홀딩스, 코오롱모빌리티그룹. 이 시점 전체 경제뉴스 카테고리 722개.

**토큰 절약 방식으로 전환(2026-07-13, 사용자 요청)**: 회사별 개별 PHP 파일+개별 wp eval-file 대신, **20개를 파일 1개에 몰아넣고 명령 1번**으로 발행. 보강(1500자 미달 시 문단 추가)도 라운드별로 스크립트 1개씩 일괄 처리(1차 20개→2차 14개→3차 2개). 중복 체크도 개별 grep 대신 회사명 리스트를 한 파일로 일괄 대조.
- **함정**: 여러 posts를 한 PHP 배열에 담을 때 본문에 큰따옴표 대신 작은따옴표로 강조 인용("위고비 효과" 등)을 쓰면 PHP 문자열이 조기 종료되어 문법 오류남 → 반드시 `php -l 파일.php`로 실행 전 린트 확인 후 wp eval-file 실행할 것. 발견 즉시 큰따옴표(" ")로 교체.
- **검색 성공률 저하 재확인**: 30여개 검색해 20개 확보(실패율 약 33%) — 코스닥 하위/중소형주로 갈수록 "2026년 1분기 실적" 검색이 아예 안 잡히거나 다른 회사(동원개발→동원산업, 대창스틸→대창, 세아특수강→상장폐지) 데이터로 오염되는 경우가 흔함. 검색 실패 시 억지로 쓰지 말고 즉시 다른 후보로 교체.
