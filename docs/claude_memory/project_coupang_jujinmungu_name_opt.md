## 스캔 함정(실측, 오탐 제거 과정)
- **"폴리"(폴리에스터/OPP·PP·PE봉투)**, **"마블"(대리석/마블코팅 팬)**을 캐릭터 키워드 목록에 넣으면 90%+ 오탐 — 목록에서 제외.
- **"원피스"**(옷 vs 애니메이션 원피스), **"이벤트"**(행사용품 vs 프로모션 표현), **"치료"**(치료복=대상표기 정상, 프롬프트 예시와 일치)도 문맥상 대부분 무관 — 리터럴 매치 대신 "이름(I)에 실제로 있는지"만 보고, 키워드(N)풀에만 있는 건 애초에 append 후보에서 forbidden 필터로 걸러지므로 방치해도 안전.
- **"디올뉴 그랜저/코나"** = 현대차 트림명(더 올 뉴), 샤넬/디올과 무관 — 명품 오탐 정규식 예외 처리.
- "안타요원형구이판"처럼 문자열 우연일치(안+타요)로 캐릭터 오탐 발생 가능 — 원본유지로 처리되니 무해하지만 계정주 확인시 설명 필요.

## 기계적 정리 규칙
- 배송/가격 스팸 제거: (당일발송/무제한공급/정품), 무료배송, 땡처리(특가) 등 리터럴 제거.
- "1+1"/"1+1+1" → "2개세트"/"3개세트"로 치환(실제 묶음수량 의미는 보존하면서 프로모션성 표현만 순화). "(사은품)" 단독 표기는 제거.
- 키워드 append시 [[feedback_bulk_name_opt_no_api_method]]의 `_BRAND_STOP`(농심/CJ/질레트 등) 교차오염 필터 재사용 — 후보 키워드에 타사 브랜드가 섞여있고 원본명/제조사에 근거 없으면 스킵. (예: "비트 액체세제"는 제조사가 실제 "라이온코리아"라 "CJ 라이온" 키워드 허용됨 — 제조사 매칭 근거 있으면 통과)
- 100자 캡, 키워드 최대 4개 추가.

**Why:** 대량 카탈로그 상품명 최적화를 API 비용 없이 세션에서 신뢰성 있게 처리하기 위해.
**How to apply:** 유진문구 외 다른 쿠팡/오너클랜 계정 엑셀도 동일 스크립트(`optimize_names.py` 패턴)로 재사용 가능 — TRUSTED_CHAR_MANUFACTURERS 화이트리스트는 카탈로그마다 제조사명이 다를 수 있어 재확인 필요.
