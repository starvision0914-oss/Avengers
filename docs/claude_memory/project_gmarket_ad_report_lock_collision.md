2026-08-21 08:20 상품별광고비+키워드 통합크롤(cron_gmarket_ad_report_kw.sh)이 25계정 전부 "실패"로 표시된 사건의 원인: 개별 계정 실패가 아니라 **크롤 시작 전 전역 락 확보 단계에서 통째로 스킵**됨.

원인 체인:
1. `cron_cpc2_on.sh`(간편광고ON, 08:01 시작, AD_SCHEDULE)가 지마켓 전역 크롤 락을 잡음
2. `cron_gmarket_ad_report_kw.sh`(08:20 시작)가 같은 락을 최대 1800초(30분) 대기하도록 `guard.preflight()`를 호출하는데, 이 호출은 25개 계정 루프 진입 **전에 한 번만** 체크됨(gmarket_ad_report_crawler.py:325)
3. ON 작업이 계정별 로그인 실패("다른광고주가 선택되었습니다" 알림창 반복)로 지연되어 08:50 이후까지 안 끝나면 대기시간(30분) 초과 → `⏭️ 건너뜀 — 락 대기 시간초과` → **25계정 전부 스킵**(개별 실패 아님)

**Why:** ON(08:01)~상품별광고비(08:20) 버퍼가 19분뿐인데, ON 자체가 25계정 순차처리(로그인 재시도 포함)라 종종 49분(08:01~08:50)을 넘겨 충돌. 11번가 쪽엔 유사 충돌 대비 재시도 안전망(`cron_ai_on_retry.sh`)이 있지만 지마켓 상품별광고비 쪽엔 없음.

**How to apply:** 대시보드에 "완료 0/25 · 실패 25계정"처럼 계정 전체가 동시에 실패로 뜨면 개별 계정 문제가 아니라 락 충돌/타임아웃일 가능성이 높음 — 먼저 `/tmp/cron_gmkt_adkw.log`에서 "락 대기 시간초과" 문구부터 확인. 조치는 보류 상태(2026-08-21 사용자가 "지금은 그냥 두고 지켜보기" 선택) — 재발하면 (a) 08:20 크론 시작시각을 08:55 등으로 늦추거나 (b) AI ON 재시도처럼 미완료시 자동 재실행 크론 추가하는 두 방안 중 선택 필요. 재크롤은 대시보드 "실패계정 재크롤" 버튼으로 충분(락이 풀린 뒤라면 정상 동작).
