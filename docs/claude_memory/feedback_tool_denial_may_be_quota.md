"사용자가 도구 사용을 거부했다"는 시스템 메시지가 뜨더라도, 항상 사용자가 의도적으로 취소 버튼을 누른 것은 아니다. 세션의 토큰/사용량 한도가 소진되어 중간에 끊긴 경우에도 겉보기엔 동일한 "거부됨" 형태로 나타날 수 있다.

**Why:** 2026-07-11 세션에서 Write 도구 호출이 거부 처리됐고, "왜 거부했냐"고 묻자 사용자는 "토큰이 모두 소진되어 중간에 중단되었다"고 답함 — 실제로는 의도적 거부가 아니었음.

**How to apply:** 도구가 거부됐을 때 사용자에게 이유를 먼저 캐묻거나 작업을 포기하지 말 것. "왜 거부하셨는지 궁금합니다" 정도로 담백하게 묻고, 사용자가 "계속해줘"라고 하면 바로 이어서 진행하면 된다. 특히 대량/반복 작업(예: 배치로 여러 파일 생성) 도중 거부가 뜨면 사용량 소진 가능성을 먼저 의심할 것.
