## 발견한 문제/개선점 (아직 미조치)
1. **profit-dashboard API 1.2초** — `/dashboard`가 30초마다 자동새로고침하는데 이 API가 느림. 다른 페이지들은 이미 최적화 이력 있음([[project_perf_audit_2026-06]] 있으면 참고) — 이 엔드포인트는 아직 미최적화.
2. **미동기화 상품 비율**: 11번가 나의상품 17,152건(2.8%), 지마켓 나의상품 26,005건(5.4%)이 14일 이상 synced_at 갱신 안 됨 — 비활성계정 상품 추정되나 미확인.
3. **스케줄 외 크롤 실행 발견**: `crawl_gmarket_ai`는 크론상 평일 9/12/18시만 도는데, 21시대에 별도로 실행 중인 걸 목격(PPID=1로 리페어런트된 상태, CPU 사용 중이라 살아있는 프로세스). 트리거 주체 불명 — 수동실행이었는지 재확인 필요.
4. **좀비 프로세스 패턴 재확인됨**: 크롤/브라우저 자동화 후 Xvfb+chrome 고아 프로세스가 다시 관찰됨(리퍼 로직이 있음에도 완전히 안 잡히는 케이스 존재, [[project_crawler_zombie_pc]] 기존 이슈와 동일 계열).

**Why:** 사용자가 "전체 쇼핑몰 시스템 전체 점검" 요청 — 큰 문제는 없었으나 위 4가지는 실제 개선 여지로 확인됨.
**How to apply:** 다음 점검 때 위 4개 항목이 해결됐는지부터 재확인. 이 메모는 시점 스냅샷이라 시간 지나면 재검증 필요(특히 미동기화 비율은 계속 변함).
