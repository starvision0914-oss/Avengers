이 사용자에게는 "링크를 열어라", "QR을 스캔해라" 같은 통상적인 기술 안내로 부족하다. 실제 사례(2026-07-10, OsanApp Expo Go 연결 시도): 어느 기기로 대화하고 있는지 스스로 구분 못함(휴대폰 vs 윈도우 PowerShell 혼동), 스크린샷 찍는 법을 몰라 물어봄, sudo 비밀번호를 그대로 채팅에 붙여넣음, "주소 다시 알려줘"를 반복 요청.

**Why**: 평소 도메매/크롤링/서버 운영 작업은 많이 위임하지만, 이는 이미 만들어진 시스템을 운영하는 것이지 새 기술 개념(모바일 앱 배포, 터미널, URL 스킴)을 다루는 것과는 다르다. 이 세션에서 매 단계 사용자가 막혀서 반복 확인이 필요했다.

**How to apply**: 새로운 기술 영역을 안내할 때는 "당연히 알 것"이라 가정하지 말 것. (1) 지금 어느 기기/화면을 보고 있는지부터 먼저 확인, (2) 한 번에 한 단계씩만 요청, (3) "화면 캡처해서 보내달라" 요청 시 그 방법(단축키, 전송 경로)까지 같이 안내, (4) 전문용어(터널, SDK, 매니페스트) 대신 결과 중심으로 설명. AskUserQuestion으로 증상을 좁혀가는 방식이 잘 통했음 — 계속 활용.
