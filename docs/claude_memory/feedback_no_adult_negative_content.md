트렌딩 키워드 대량 작성 작업(201~250번 배치 진행 중) 도중 사용자가 "부정적인 글이나 선정적인글 성인글등은 제외해야해"라고 명시적으로 지시함(2026-07-26).

**적용 방식 (두 층위로 구분):**
1. **성인/선정적 콘텐츠(19+ 웹툰·게임·명백한 성적 소재)**: 키워드 자체가 이런 소재면 해당 항목은 **작성하지 않고 스킵**한다. 이는 [[feedback_no_skip_write_short]](자료부족시 스킵 금지)의 예외 — 그 규칙은 "자료가 부족해서" 스킵하는 것을 막는 것이고, 이건 "콘텐츠 성격이 부적절해서" 의도적으로 제외하는 것이라 서로 충돌하지 않음.
2. **부정적/논란성 소재(범죄, 스캔들, 비위, 참사 등)**: 완전히 스킵하지는 않되, 자극적/선정적으로 다루지 않고 중립적·사실 위주로 절제해서 서술한다. 필요 이상으로 논란을 부각하거나 자극적 제목을 쓰지 않는다.

**Why:** 애드센스 승인·광고주 친화성과 브랜드 이미지를 위해 성인/선정적/과도하게 부정적인 콘텐츠는 광고 게재 제한 사유가 되거나 사이트 品질을 해칠 수 있음.

**How to apply:** [[project_highcpc_content_batch]] 및 트렌딩 키워드 시리즈(부동산/건강금융법률/트렌드 전체) 작업 시 항상 이 필터를 적용. 새로 배치 에이전트를 띄울 때마다 프롬프트에 이 지침을 포함시킬 것 — 한 번 말했다고 이후 세션(새 에이전트)이 자동으로 아는 게 아니므로 매번 명시해야 함.
