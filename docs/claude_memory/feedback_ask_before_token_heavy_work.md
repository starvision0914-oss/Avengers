토큰을 많이 사용하는 업무는 사용자에게 비용(청구)으로 이어지므로, 시작하기 전에 반드시 "진행해도 되냐"고 먼저 물어봐야 한다.

**Why:** 사용자가 직접 밝힘 — "토큰을 많이 사용하는 업무는 나에게 많이 들어간다(비용 청구)". 2026-07-11 코스피 종목 뉴스 글 대량 작성 작업(종목당 웹서치 2회+글작성+발행, 90개 이상 반복) 도중에 나온 지시.

**How to apply:** 반복적으로 웹서치+콘텐츠생성을 여러 차례(대략 10회 이상) 수행해야 하는 작업, 또는 규모가 불분명한 "계속 이어가줘" 류의 대량 반복 작업을 시작하기 전에는, 몇 개 단위로 진행할지/얼마나 반복할지 먼저 확인받는다. 이전에 사용자가 "그만 물어보고 200개 되면 물어봐"라고 했더라도, 이 메모리(비용 우려)가 나중에 나온 더 구체적인 지시이므로 이것을 우선한다 — 확인 없이 대량 반복하지 말 것.
