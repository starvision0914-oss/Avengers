크롤/작업 실패를 보고할 때, 실패 사실만 말하고 끝내면 안 된다. 그 이후 자동재시도나 다음 회차
크론으로 이미 해소됐는지까지 확인해서 한 번에 같이 보고해야 한다.

**Why:** dlwodbs666 지마켓 상품수집이 09/17 로그인 실패했다고만 보고했더니, 사용자가 "그 이야기까지
결과에 말해줘야지 실패했다고만 하면 어떻게해"라고 지적. 실제로는 09/18 새벽 정기크론이 이미
자동으로 재수집해서 정상 해소된 상태였는데, 그걸 확인 안 하고 실패만 던져서 사용자가 직접
"다시 했어?"라고 재차 물어봐야 했음 — 불필요한 왕복이 생김.

**How to apply:** 크롤/작업 실패 사실을 발견하면, 보고 전에 반드시:
1. 다음 스케줄(재시도 크론, 워치독, 다음날 정기크론 등)이 이미 돌았는지 로그로 확인
2. 돌았다면 그 결과(성공/실패)까지 확인
3. "X일에 실패했지만 Y일 자동재수집으로 이미 해소됨" 또는 "아직도 실패 중, 수동조치 필요" 형태로
   한 번에 같이 보고 — 실패 사실만 던지고 사용자가 후속 질문하게 만들지 말 것.
