## 배경
지마켓 449,746건 + 11번가 393,589건 판매중 상품을 클린위반 의심(모의총포/도검류/성인용품 등)
키워드로 스캔하면서(2026-07-05) 여러 차례 정밀화하며 발견한 오탐 패턴. 다음에 같은 스캔할 때
처음부터 이 목록으로 걸러서 시간 절약할 것.

## 오탐 확정 사례 (실제로는 위반 아님)
- **"표창"** → 대부분 "상장/표창장"(수료증) 상품. 도검류(표창=수리검) 아님.
- **"삼단봉"** → 접이식 호신용 경찰봉형. 도검류와 다른 별도 카테고리(호신용품)로 합법 유통됨.
- **"에어건"(단독)** → 대부분 워터건 장난감(물총) 또는 에어공구(에어컴프레서/카플러/유압공구/
  스프레이건/글루건 등). 실제 모의총포는 "비비탄권총/BB탄권총/가스총/가스건"처럼 더 구체적인
  키워드로 걸러야 함.
- **"전동건"** → "마사지건/안마기"(전동안마기)와 혼동 다발. 제외 필요.
- **"레플리카"** → 스포츠공(축구공 등) 업계에서 "레플리카 매치볼"은 정식 훈련용 용어, 명품
  위조와 무관. 브랜드명(샤넬 등)과 결합된 경우만 위험.
- **"스틸레토"** → 하이힐 구두(스틸레토 힐). 스틸레토 나이프 아님.
- **"정글도/정글낫"** → 캠핑·벌목용 정식 도구, 합법 유통. 흉기형 도검류 아님.
- **"자동칼"** → "자동칼날복귀 안전커터칼"처럼 산업안전용구의 기능설명으로 자주 등장.

## 실제 위반/확인필요로 남은 것
- **아카데미과학 등 정식 완구브랜드 BB탄권총/에어소프트건** — 위법은 아니나 KC인증 여부는
  개별 확인 필요(완전 오탐은 아님, "확인필요"로 분류).
- **"발리송 연습용 트레이너"(나비칼/카람빗형)** — 날이 있는 실물인지 학습용 뭉툭한 것인지
  키워드만으로는 판단 불가, 상세페이지 확인 필요(11번가에서 8건 미확인 상태로 남음).
- **"발로란트 카람빗... 굿즈"** → 게임 스킨 테마 장난감/열쇠고리 추정, 위험도 낮음(칼 아님).

**Why:** 이 오탐들을 매번 새로 발견하느라 스캔 정밀화에 시간을 반복 소모함(지마켓 1차 스캔
395건 → 정밀화 후 10건, 11번가도 비슷한 과정 거침).
**How to apply:** 향후 클린위반 스캔 시 위 제외 키워드 목록을 스캔 스크립트에 처음부터
반영해서 반복작업 줄일 것.
