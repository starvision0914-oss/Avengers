부동산 단지명 시리즈("OO단지 세대수, 입주시기와 단지 정보 총정리" 패턴) 제목을 후킹형으로 바꿀지 물었더니, 사용자가 **지금처럼 검색어 일치형 유지**를 선택함(2026-07-24).

**Why:** 이 시리즈의 목적은 "많이 클릭되게"가 아니라 "정확한 단지명을 검색하는 구매의도 높은 사람"을 잡는 것. 클릭률보다 CPC(광고단가)가 중요한 고단가 카테고리 전략이라, 정확한 단지명 매칭이 후킹 문구보다 우선.

**How to apply:** [[project_highcpc_content_batch]] 시리즈(부동산/건강/금융/법률)는 앞으로도 "키워드 + 세대수/입주시기/총정리" 식 명확한 서술형 제목 유지. 흥미 유발형 제목으로 바꾸자고 먼저 제안하지 말 것. 단, 핫이슈(인물/이슈) 시리즈는 이 규칙과 무관 — 그쪽은 원래도 다른 스타일.
