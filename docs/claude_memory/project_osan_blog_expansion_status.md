208개 글 중 2026-07-11 기준 63개 완료(1500자 이상), 145개 미달(대부분 850~1250자). 사용자가 "이 글까지만 진행하고 마무리"라고 지시해 중단.

**진행상태 확인법**: `wp eval-file`로 `get_posts()` 순회하며 `mb_strlen(wp_strip_all_tags(strip_shortcodes($post->post_content)))` < 1500인 ID 목록 조회. 미완료 ID는 129,131-160(일부),163-293 범위에 다수 분포(정확한 최신 목록은 재조회 필요, 매번 바뀜).

**재개 시 방법**: `<!-- wp:heading {"level":3} -->\n<h3>관련 글</h3>` 마커 앞에 PHP str_replace로 H2+문단 블록 삽입 → `wp_update_post()`.

**교훈 1 - 문단 길이 계산 착각**: 4-5문장 한글 문단을 "250~300자"로 예상했지만 실측은 150~200자 수준. 매번 1500자 미달로 2~3라운드 보강이 반복됨. 다음엔 처음부터 목표보다 훨씬 크게(3~4개 섹션, 각 300자+ 체감) 써야 함.

**교훈 2 - 병렬 서브에이전트가 세션 한도 소진**: 182개 글을 3개 백그라운드 에이전트(각 60개)로 병렬 처리 시도 → 각 에이전트가 컨텍스트를 새로 구성하며 개별 글 내용을 다시 읽어 3배 중복 소모 → 세션 토큰 한도 도달로 3개 모두 실패(2026-07-11, 4:50am KST 리셋). 이후 메인 세션에서 직접 순차 처리로 전환. **향후 대량 작업은 서브에이전트 병렬화보다 메인 세션에서 직접 작은 배치(10~20개)로 순차 처리하는 게 안전.**
