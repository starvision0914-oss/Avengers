블로그/글 대량 생성 작업에서 특정 항목(회사 등)의 검색 데이터가 부족하다고 판단해 자동으로 건너뛰려 하자, 사용자가 "건너뛰지 말고 글자수 적어도 되니깐 키워드로 진행해줘"라고 정정함.

**Why:** 처음엔 "데이터 부족하면 자동으로 건너뛰기"를 사용자가 직접 승인했었지만, 실제로 진행해보니 스킵되는 비율이 예상보다 높아지자(10개 시도 중 4~6개 스킵) 방침을 뒤집음. 완전한 최신 실적 수치가 없어도, 회사 개요·일반적 사업 설명 수준의 정보만으로도 충분히 짧은 글을 쓸 수 있다는 판단.

**How to apply:** [[project_osan_kospi_news_series]] 류의 대량 콘텐츠 생성 작업에서, "데이터 부족시 스킵"을 사전 승인받았더라도 스킵 비율이 눈에 띄게 높아지면(체감 30%+) 사용자에게 먼저 확인하거나, 스킵 대신 "짧게라도 작성" 옵션을 함께 제시할 것. 기본값을 스킵보다 "짧게 작성"으로 두는 편이 이 사용자에게는 더 맞음.
