사용자는 크롤링 등 장시간 작업 진행 시 기본적으로 **5분마다 진행상황을 보고**하라고 요구함(2026-06-12). "무조건" 강조.

**단, 2026-08-24 정정**: 계정별 완료 알림이 너무 잦아 시끄럽다며(56개 계정 순차 재크롤 중) **"진행사항은 30분에 한번만 해줘"로 명시적으로 빈도를 낮춤.** 즉 5분은 기본값이지 고정 규칙이 아님 — 작업이 오래 걸리고 계정 수가 많아 알림이 잦아지면 사용자가 직접 빈도 조정을 요구할 수 있으니, 그 지시가 있으면 즉시 새 빈도를 따를 것.

**Why:** 크롤러가 캡차/로그인 실패로 멈춰도 사용자가 모르고 방치되는 일이 있었음. 침묵하면 문제를 늦게 안다. 반대로 너무 잦으면 소음이 되어 사용자가 직접 빈도를 줄여달라고 요청함.

**How to apply:** 장시간 크롤·복구 작업을 돌릴 때 기본 ~5분 간격으로 보고하되, 계정 수가 많아 완료 알림이 자주 오는 작업은 사용자가 별도 빈도(예: 30분)를 지정할 수 있음 — 지정되면 그 주기를 따르고, 개별 완료 알림은 내부적으로만 확인하고 취합해서 보고. 단발 질문엔 불필요. 문제 발견 시 "정상"에서 멈추지 말고 근본원인까지 파고들어 먼저 보고. [[feedback_crawling_rule]] [[project_gmarket_captcha_login]]
